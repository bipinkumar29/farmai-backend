🌾 AI-Based Farmer Query Support and Advisory System (FarmAI)
Role: Cloud Backend & API Integration Developer

Environment: AWS EC2 (Ubuntu 24.04), Docker, FastAPI, Python, LLM (Google Gemini API), Machine Learning (NLP)

📌 Project Overview

A cloud-native, intelligent backend system integrating Large Language Models (LLMs) via the Google Gemini API. The system leverages Machine Learning (ML) and Natural Language Processing (NLP) to process, understand, and resolve multilingual agricultural queries in real-time.

🏗️ System Architecture & Backend

Backend Framework: Utilized FastAPI for high-performance, asynchronous API routing.

AI & ML Integration: Seamlessly connected the Google Gemini API (LLM) to generate accurate agronomic advisory, effectively decoupling heavy ML inference workloads from the core application server.

Cloud Infrastructure: Hosted securely on an AWS EC2 instance, utilizing custom Security Groups to restrict access and manage API traffic safely.

⚙️ Deployment & Version Control

Containerization: Dockerized the entire application backend to eliminate dependency conflicts and ensure identical environment setups from local to AWS production.

Code Management: Leveraged Git and GitHub for version control and smooth code integration.
